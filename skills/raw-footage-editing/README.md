# Raw Footage Editing Skill

Technical methodology for cutting and captioning real raw video (phone/camera recordings) — silence-cut, semantic trim, word-synced burned-in captions via ffmpeg, auto-editor, and whisper.cpp.

Not to be confused with `video-production` / `remotion-video`, which cover scripting and rendering **synthetic** motion-graphics video from a text brief. This skill processes footage that already exists as a file.

See [SKILL.md](./SKILL.md) for the full methodology.
