# Video Editor Agent

Raw footage editor for GrowthOS. Turns an actual video file into a captioned vertical cut using silence-cut, semantic trimming, and word-synced burned-in captions — via ffmpeg, auto-editor, and whisper.cpp.

Complementary to `video-producer` (synthetic Remotion motion graphics from a brief, no source footage).

See [AGENT.md](./AGENT.md) for full specification.
